# What is an Operating System?

An **Operating System (OS)** is the main software that manages a computer.

It allows the **user, applications, and hardware** to work together.

Examples of operating systems include **Windows, macOS, Linux, Android, and iOS**.

We need an **Operating System (OS)** because it manages things like the **CPU, memory, files, devices, and security**.

Without an OS, applications would have to manage these things themselves, which could cause problems. The OS manages these resources and makes sure everything can work together.

## System Privilege Layers

A computer has different **permission levels** to help keep the system safe and prevent problems.

- **Kernel Space:** The protected part of the OS that can directly access and manage the **CPU, memory, storage, and hardware**.
- **User Space:** Where normal applications run. They cannot directly access the hardware and have to ask the **kernel** to do certain tasks using **system calls**.

This separation helps keep the computer **secure and stable**. If one application has a problem, it is less likely to affect the rest of the system.

## Operating System Duties

An **Operating System (OS)** has several important jobs that help a computer run properly.

- **Process Management:** Manages running programs and decides how much **CPU time** each program gets.
  - Example: Running a browser, music player, and other apps at the same time.

- **Memory Management:** Manages **RAM** and makes sure applications have the memory they need without interfering with each other.
  - Example: Giving each open application some RAM to use.

- **File System Management:** Organises **files and folders** and manages things like names, locations, and permissions.
  - Example: Creating a folder or saving a photo.

- **User Management:** Manages **user accounts, passwords, and permissions**.
  - Example: Making sure one user's files cannot be accessed by another user without permission.

- **Device Management:** Helps the OS communicate with **hardware devices** using drivers.
  - Example: Connecting a mouse, printer, or external hard drive.

## Operating System Security

An **Operating System (OS)** has built-in security features that help protect the computer, users, and their data.

- **Authentication:** Checks who you are using things like passwords or biometrics.
- **Permissions:** Controls what users and applications can access or change.
- **Isolation:** Keeps applications separated so that problems in one app are less likely to affect other apps.
- **System Protection:** Protects important system files and settings from unauthorised changes.

## OS Interfaces

There are two main ways to interact with an **Operating System (OS)**:

- **Graphical User Interface (GUI):** Uses **windows, icons, menus, and buttons** to interact with the computer.
  - Example: Clicking on a folder to open it.

- **Command-Line Interface (CLI):** Uses **text-based commands** to interact with the computer.
  - Example: Typing a command to view the contents of a folder.

The **GUI is usually easier for beginners**, while the **CLI can give you more control and can be faster** once you know the commands.

## The Operating System Landscape

Different devices and tasks use different types of **Operating Systems (OS)**.

- **Desktop:** Used on personal computers for work, gaming, and everyday tasks.
  - Examples: Windows, macOS, Linux.

- **Server:** Used to host websites, databases, and cloud services. Servers are often managed remotely.
  - Examples: Linux Server, Windows Server.

- **Mobile:** Designed for smartphones and tablets. They are designed to work with touchscreens and use power efficiently.
  - Examples: Android, iOS.

- **Embedded:** Built into devices such as cars, smart TVs, routers, and appliances. They are usually designed for a specific purpose.

- **Virtual/Cloud:** Used for virtual machines and cloud computing. They can be created and changed quickly when needed.

## Real World Operating Systems

There are many different **Operating System (OS) families**, and they are used for different types of devices and tasks.

### Desktop

- **Windows:** Widely used on personal computers.
  - Examples: Windows 10, Windows 11

- **macOS:** Apple's desktop operating system.

- **Linux:** A family of open-source operating systems called **distributions (distros)**.
  - Examples: Ubuntu, Debian, Fedora

### Server

- **Windows Server:** Used in businesses, networks, and data centres.

- **Linux:** Commonly used for web servers because it is reliable and flexible.
  - Examples: Ubuntu Server, Debian, Red Hat

- **Unix:** Used by some large organisations and industries.
  - Examples: IBM AIX, Oracle Solaris

### Mobile

- **Android:** Used on smartphones, tablets, and other smart devices.

- **iOS:** Apple's operating system for iPhones and other Apple devices.

### Embedded and IoT

- **Embedded Linux:** Used in devices that are designed for specific tasks.
  - Examples: OpenWrt, Ubuntu Core

- **Real-Time OS (RTOS):** Designed for systems where tasks need to happen within specific time limits.
  - Examples: FreeRTOS, VxWorks, QNX

### Virtual and Cloud

- **Cloud/Virtual Machines:** Operating systems running on virtual machines in data centres and cloud environments.
  - Examples: Ubuntu, Amazon Linux, Rocky Linux

- **Container-Optimised OS:** Lightweight operating systems designed to run containers.
  - Examples: Alpine Linux, Bottlerocket, Flatcar Linux

## Why So Many Operating Systems?

Different devices need different features from an **Operating System (OS)**.

- **Laptops:** Need to be easy to use and support many tasks at once.
- **Servers:** Need to be stable, secure, and able to run for long periods of time.
- **Mobile devices:** Need to save battery and work well with mobile hardware.
- **Embedded systems:** Need lightweight operating systems designed for specific tasks.

Different OS developers also focus on things like **performance, security, ease of use, openness, and customisation**.

Because different devices have different needs, there is **no single OS that is perfect for everything**.
