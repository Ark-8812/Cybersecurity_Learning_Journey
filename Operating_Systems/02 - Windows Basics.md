# Windows Fundamentals

## Windows Account Types

Windows commonly has three types of user accounts:

- **Guest:** A restricted account mainly used for temporary access. It has limited permissions and cannot make major changes to the system.
- **User:** An account used for everyday tasks, such as running applications and changing personal settings. It cannot make system-wide changes.
- **Administrator:** A privileged account with full control over the system. It can install software, change system settings, and manage other user accounts.

## Main Areas of the Windows Desktop

There are two main areas of the Windows desktop:

- **Desktop:** The main workspace where files, folders, shortcuts, and other items can be accessed.
- **Taskbar:** A bar at the bottom of the screen that provides quick access to applications, system tools, settings, and notifications.

## Main Parts of the Windows Desktop

1. **Desktop Icons:** Shortcuts to things like the Recycle Bin, folders, and frequently used applications. These can be customised.
2. **Start Menu:** The main place to access applications, settings, and power options. You can also use it to log out, restart, or shut down the computer.
3. **Search:** Allows you to quickly find applications, files, folders, and system settings by searching for keywords.
4. **Task View:** Shows all currently open windows and allows you to quickly switch between them.
5. **Pinned Applications and Folders:** Allows you to pin frequently used applications and folders for quick access.
6. **Network and Audio Settings:** Provides quick access to network and audio settings, which can be changed to suit your needs.
7. **Date and Time:** Shows the date and time and can also open a calendar. Date and time settings can be accessed here.
8. **Notifications:** Displays notifications from the computer and applications. You can also access some system settings from this area.

## Installing Applications

There are a couple of different ways to install applications on Windows:

1. **Microsoft Store:** A built-in store for downloading and installing apps. It provides a safer and more controlled way to install applications. The Microsoft Store is not available by default on Windows Server.
2. **From the Internet:** Applications can be downloaded directly from a trusted vendor's website. Installers usually come as `.exe` or `.msi` files and guide you through the installation process.

## Diving Into Settings

Windows has different tools that allow you to change and manage how your computer works.

1. **Windows Settings:** The main place to change system, device, personalisation, and security settings.
2. **Control Panel:** An older Windows tool that still provides access to some settings and administrative features.

Both **Windows Settings** and the **Control Panel** allow you to change things such as display and audio settings, user accounts, applications, network settings, accessibility, and security.

## The Task Manager

**Task Manager** is a built-in Windows tool that lets you see what is happening on your computer in real time.

It can show running applications and background processes, as well as information about system performance, such as **CPU and memory usage**.

Task Manager has five main tabs:

1. **Processes:** Shows running applications and background processes and how many resources they are using.
2. **Performance:** Shows graphs and information about resources such as the **CPU, memory, and network**.
3. **Users:** Shows the users currently logged into the computer and the resources they are using.
4. **Details:** Shows more detailed information about running processes, including their **Process IDs (PIDs)**.
5. **Services:** Shows Windows services and whether they are currently running or stopped.

## Native Windows Security

Windows has built-in security tools that help protect the computer from threats such as **malware, unsafe applications, and unauthorised network access**.

### Windows Security

**Windows Security** is the main place for managing Windows' built-in security features.

It includes several areas:

- **Virus & Threat Protection:** Helps detect and remove malware using real-time protection and different types of scans.
- **Firewall & Network Protection:** Controls network traffic to help prevent unauthorised access.
- **App & Browser Control:** Helps protect against unsafe applications, files, and websites.
- **Device Security:** Provides hardware-based security features that help protect the computer.
