# Computer Types

A **computer** is a device that processes information and can performs tasks. Computers come in many different forms, from laptops, phones, washing machines and even your doorbell. 

## Personal Computers

### Laptop

A **laptop** is a portable computer designed for everyday use.

Things you can use a laptop for:

- Browsing the internet
- Coding/Programming
- Gaming
- Schoolwork

**Main advantage:** Portability

### Desktop

A **desktop** is a computer designed to stay in one place. 

It does not need to focus on portability hence it can have more space and focus for:

- Better cooling
- More powerful components
- More upgrade options

**Main advantage:** Performance and enhancable 

## Workstation

A **workstation** is a powerful computer designed for professional and demanding tasks.

Things that it may be used for:

- 3D modelling
- Engineering
- Scientific simulations
- Video production
- Large calculations

Workstations are usually built with **performance, reliability, and professional workloads** in mind.

## Server

A **server** is a computer that provides services or resources to other computers over a network.

A server can provide:

- Websites
- Files
- Games
- Databases
- User accounts

A server's main purpose is to **provide services to other devices**
